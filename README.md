# Jarvis Assistant

A futuristic AI Voice & Automation Assistant rewritten as a high-performance React application, preserving all original Android features and architecture.

## Highlights & Ported Features

- **Liquid Glass Dynamic Themes**:
  - Liquid Sunset (default theme: vibrant warm amber/orange and rose glow)
  - Liquid Obsidian (deep cyber cyan and electric blue)
  - Liquid Ruby (Stark arc reactor crimson)
  - Liquid Pearl (clean high-contrast sapphire edition)
- **Interactive Concentric Particle Orb**:
  - High-performance canvas-based dynamic audio visualizer with multi-layer counter-rotating orbital arcs, volumetric halos, and reactive state indicators (`IDLE`, `LISTENING`, `THINKING`, `SPEAKING`, `ERROR`).
- **Multimodal AI Voice & Speech Recognition**:
  - Duplex voice pipeline supporting continuous speech recognition, real-time audio amplitude analysis, and neural text-to-speech with persona customization (Jarvis Pro, Naira Companion, Girlfriend/Boyfriend modes, TechGPT X, Focus).
- **Persistent Long-Term Memory Engine**:
  - SQLite/Room-equivalent web store categorized into Personal, Preferences, Contacts, Routines, and Notes with semantic fact extraction and CRUD management.
- **Agent Task Engine & 4-Step HUD**:
  - Verified automation orchestrator for YouTube playback/searches, WhatsApp messages/calls, telephony dialing, brightness and volume controls, web searches, and flashlight toggles.
- **Visual Grounding & Screen Perception HUD**:
  - Display capture and target bounding box visualization.
- **Biometric Owner Voice Profile**:
  - Acoustic vector enrollment with sensitivity threshold calibration.

## Technology Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS with custom liquid glass refractions
- **AI Integration**: Gemini Models (`@google/genai`) & local adaptive persona engine
- **Audio & Speech**: Web Speech API & Web Audio API (AnalyserNode)
